# Bootstrap lead paragraph

A standout opening paragraph (`.lead`).

## Usage

``` r
bs_lead(..., class = NULL)
```

## Arguments

- ...:

  Paragraph content and named HTML attributes.

- class:

  Extra classes.

## Value

A paragraph tag.

## Examples

``` r
bs_lead("This is a lead paragraph.")
#> <p class="lead">This is a lead paragraph.</p>
```
